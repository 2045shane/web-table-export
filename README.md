# 网页表格导出

Cut：`WEB-EXPORT-CUT-2026-10-28-v1`（表格导出范围，本刀不重开）  
收费墙：`PLUGIN-PAYWALL-CUT-2026-10-29-v1`  
界面和模块地图（改配额 / 许可码前先看）：[`FEATURE_MAP.md`](FEATURE_MAP.md)

把**当前网页里已经看得见的表格**导出成 CSV 和 Excel（`.xlsx`）。这是一个 Chrome Manifest V3 扩展，主路径是工具栏弹出窗口，标题为「导出」。

界面默认中文，可以切到 English。本仓库可以直接「加载已解压的扩展程序」，没有构建步骤。运行时不依赖付费包、支付 SDK、服务器配额或 API key。本切**不上架**商店付费，也没有应用内购买。

## 这个版本做什么

- 普通网页里的 `<table>`
- 财务 / 电商后台常见的表格 DOM：
  - Element、Ant Design 一类控件（表头、表身分成两张表，并跳过左右固定列的克隆）
  - `role="grid"` / `role="table"` 的网格
  - 带 `.table-row` / `.el-table__row` / `.ant-table-row` / `.ag-row` / `.data-row` 的行
- 同一份数据可以下载 **CSV** 和 **Excel**。两个按钮在免费档就能用，都会生成真实文件
- 免费额度每天 3 次，单次最多 100 行，记在这台浏览器里。有效许可码会抬高这两项限制

## 这个版本不做什么

- 不抓 Google Maps，也不抓商家列表
- 不自动翻页、不自动滚动把更多行加载进页面、不打开别的网站
- 不扫描跨域 iframe，只读当前页主框架
- 不上架 Chrome 网上应用店的付费商品，不接支付 SDK，不连后端配额或许可服务器
- 不读「所有网站」。权限只有你点工具栏之后的当前标签页

虚拟列表如果只把窗口里的行放进 DOM，导出的就是这些行。已经在 DOM 里、只是要往下滚动才进入窗口的行，会一起导出。

## 权限

`manifest.json` 只申请：

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 你点「导出」之后，临时读取**当前**标签页 |
| `scripting` | 把同一份解析脚本注入这个标签页 |

没有 `host_permissions`，没有 `content_scripts`，也不会在你浏览时后台运行。浏览器内置页（`chrome://` 等）和扩展商店页读不了，弹出窗口会说明原因，而不是假装成功。

配额存在扩展页面自己的 `localStorage` 里，所以没有申请 `storage` 权限。换一个浏览器配置文件、或换一台电脑，次数各自计算。

## 免费额度与已解锁额度

数字只写在 `src/quota.js`。弹出窗口用这些常量填文案，不另写一套「每天 3 次」。

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `FREE_DAILY_EXPORT_LIMIT` | 3 | 免费档每天成功导出的次数 |
| `FREE_EXPORT_MAX_ROWS` | 100 | 免费档单次最多行数（含这 100 行） |
| `PAID_DAILY_EXPORT_LIMIT` | 1000 | 有效许可码之后的每日次数（极高，仍是本机计数） |
| `PAID_EXPORT_MAX_ROWS` | `null` | 有效许可码之后**本机无硬顶**（不再按行数截断或拒绝） |

付费档的选择写死在这一刀里：每日次数用 1000（高于免费 ×5），单次行数用本机无硬顶，而不是再设一个 500 或 1000 的行数天花板。

```javascript
var FREE_DAILY_EXPORT_LIMIT = 3;
var FREE_EXPORT_MAX_ROWS = 100;
var PAID_DAILY_EXPORT_LIMIT = 1000;
var PAID_EXPORT_MAX_ROWS = null;
```

弹出窗口主路径会显示「每天 3 次」和今日剩余。免费档另外一行写明「免费单次最多 100 行」。

- 按本机日期计算，过了零点恢复
- 点一次「导出 CSV」或「导出 Excel」各算 1 次。两个格式都不锁在付费档后面
- 扫描、失败、没有表格、超过单次行数，都不扣次数
- 用完当日次数：剩余显示 0，导出按钮停用，**不会下载空文件**。同一屏能看到「有问题请联系我」、小红书「珊哥爱读书」，以及许可码输入框
- 表格行数超过免费单次上限：拦住这一次导出，说明实际行数和 100 这个上限，**不会悄悄截成 100 行再当成功**

## 解锁（许可码或私信）

有问题请联系我。小红书私信「珊哥爱读书」。

两条路都能用，没有第三条付款路：

1. 把本机许可码贴进弹出窗口并保存
2. 私信「珊哥爱读书」索取许可码（这一刀不在扩展里收款）

许可码格式是 `WTE1.PAID.` 加 8 位十六进制校验，算法在 `src/quota.js` 的 `licenseChecksum`（FNV-1a 32 位，只对正文 `WTE1.PAID` 计算）。校验在浏览器里完成，不访问服务器。当前算法对应的码是：

```text
WTE1.PAID.3c5a2030
```

这不是 API key，也不是支付凭证。源码公开，所以读仓库的人可以自己算出同一串；它只用来把「随便写一句备注」和「这台浏览器接受的许可码」分开。

保存后发生的事：

- **有效**：`licenseNote` 存的是校验过的码。每日上限改为 1000，单次行数改为本机无硬顶。已经用掉的当日次数保留，但可以从 3 次上面继续导出
- **清除**（清空后保存，或点「清除」）：回到免费档。若当天已经导出超过 3 次，剩余变为 0，导出再次被挡住
- **无效**：弹出窗口用中文或英文说明码无效、当前仍是免费档，并清掉已存的码。旧版本那种只把文字放进 `licenseNote`、不抬配额的行为已经去掉；对不上校验的备注不会解锁

本切没有 Chrome 网上应用店付费上架，没有支付 SDK，也没有服务端计费或配额。

## 服务条款与可见范围

只导出你当前打开的页面上、没有被隐藏的表格行。请遵守目标网站的服务条款。不要用它去绕过登录、验证码、付费墙，或把网站不打算公开下载的数据批量拉走。

隐藏方式包括：`hidden`、`display: none`、`visibility: hidden`、`opacity: 0`、`aria-hidden="true"`，以及零尺寸或藏到页面左外侧的节点。

空表、只有表头、或这一页根本没有表格时，会给出中文或英文错误，**不会下载空文件**。

## 列名规则

解析器只有一套，标识是 `visible-table-v1`（`src/parser.js`）。弹出窗口注入这个文件，不再写第二套规则。列名与界面语言无关。

1. 有 `<thead>` 时，里面的可见行都是表头。多行表头用 ` / ` 拼成一列，相邻重复的文字只留一次。例如「金额」跨两列，下一行是「税前」「税后」，列名是 `金额 / 税前` 和 `金额 / 税后`。
2. 没有 `<thead>` 时，若第一行全是 `<th>`，把这一行当表头。
3. 否则没有表头，列名是 `column_1`、`column_2`……
4. 表头的 `colspan` 会占多列，并重复这份表头文字。数据单元格的 `colspan` 只把文字放在左起第一列，其余列留空，避免后面的列错位。
5. `rowspan` 的文字会填进下面被合并的每一行。
6. 单元格文字会去掉首尾空白，并把中间连续空白收成一个空格。
7. 空表头变成 `column_N`（N 是从 1 开始的列序号）。
8. 重名时，第一列保持原名，后面的加上 `_2`、`_3`。所以两个「备注」会变成 `备注` 和 `备注_2`；跨两列的「金额」会变成 `金额` 和 `金额_2`。
9. 后台控件末尾那种空的占位列（Element 的 gutter）如果自动列名且整列没数据，会去掉。
10. 格子里没有文字时，读取文本框、多行文本或下拉框里当前看得见的值。隐藏域、勾选框不拿来当文字。图片没有文字时用 `alt`。
11. 所有导出值都是文本。订单号、前导零不会被改成数字。CSV 里以 `=`、`+`、`-`、`@` 开头的格子会加一个单引号，避免表格软件把它当公式。

固定夹具 `fixtures/ac-s02-visible-tables.html` 的第一张表，列名就是：

`订单号`、`商品`、`金额`、`金额_2`、`column_5`、`备注`、`备注_2`

对应的稳定 JSON 在 `fixtures/ac-s02-visible-tables.expected.json`。

## 加载已解压的扩展程序

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选中本仓库根目录（里面要有 `manifest.json`）
5. 用下面的方式打开示例页（直接双击 HTML 时，Chrome 默认不让扩展读 `file://`）：

```bash
python3 -m http.server 8765
```

6. 浏览器打开 `http://127.0.0.1:8765/demo/orders.html`
7. 点击工具栏里的「导出」

若本地文件必须用 `file://`，到扩展详情页打开「允许访问文件网址」。

本切没有侧栏：`sidePanel` 不在允许的权限里。主路径就是这个弹出窗口。

## 开发

加载扩展不需要 `npm`。要跑不变量检查、解析、CSV、xlsx 和配额测试：

```bash
npm install
npm test
```

`npm test` 会先跑 `npm run lint`（`scripts/check-paywall-invariants.mjs`），再跑 `node --test test/*.test.js`。不变量脚本不过，整次测试就是失败。它拦住已经出过一次的回退：`licenseNote` 只存文字却不抬配额、免费次数不写在唯一的 `FREE_DAILY_EXPORT_LIMIT = 3`、导出前把行截短、把 CSV 或 Excel 锁进付费档。同一条命令也在 `.github/workflows/ci.yml` 里。

测试用的 `jsdom` 只在开发时使用，不会打进扩展。
